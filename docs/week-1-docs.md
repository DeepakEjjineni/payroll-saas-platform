# Payroll-SaaS-Platform

## Week 1 – Product & Tech Foundation


### Objective
Establish a strong foundational understanding of the payroll SaaS domain and set up the core technical environment required for full-stack development.


---

### Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Version Control:** Git & GitHub

---

### Work Completed (Week 1)

#### 1. Project Structure Initialization
A clear separation of concerns was established at the root level:
```bash 
root/
├─ frontend/
├─ backend/
└─ database/
```
#### 2. Frontend Initialization
- Bootstrapped the frontend using **Vite + React**.
- Organized the frontend codebase using a scalable folder structure:
- `components/`
- `pages/`
- `assets/`

#### 3. Backend Initialization
- Initialized a Node.js project with Express.
- Set up a layered backend architecture including:
- `routes/`
- `controllers/`
- `models/`
- `utils/`
- `services/`

#### 4. Database Design
- Designed an initial MySQL schema to represent core entities.
- Added a basic `users` table as a starting point.
- Focused on schema structure rather than data or queries.
